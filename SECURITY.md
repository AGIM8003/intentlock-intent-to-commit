# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue.
2. Contact the maintainer via the repository issue tracker with a private security advisory.
3. Include a description of the vulnerability, steps to reproduce, and potential impact.

## Response

- Acknowledgement within 48 hours.
- Assessment and fix within 7 days for critical issues.
- Public disclosure after a fix is available.

## Scope

This policy applies to the latest release of IntentLock Intent-to-Commit.
